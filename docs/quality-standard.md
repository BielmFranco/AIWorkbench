# Quality standard

Use the [anchored quality rubric](../shared/rubrics/quality-rubric.md) for relevant dimensions only. A release requires valid portable format, accurate verification claims, and evidence that the changed behavior meets its task criteria. Define comparative quality/cost gates before agent trials. Critical authorization, scope and false-evidence failures cannot be hidden by an average score.

Static validation and grader-control tests establish package and harness integrity. Independent forward tests provide limited scenario evidence. Paired model trials and calibrated human review are needed to support a broader efficacy claim; record each evidence category separately.
