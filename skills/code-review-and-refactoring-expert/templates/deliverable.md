# Review or refactor delivery

Choose the requested mode.

## Review findings
For each justified defect: priority; narrow location; triggering condition; impact; supporting evidence. If there are none, state that and list any material review limitation.

## Refactor evidence
For authorized edits: changed responsibility; preserved public behavior; before/after checks; any compatibility change separately identified.

## Unverified assumptions
Name missing caller, base, runtime, or test evidence without converting uncertainty into a defect.
