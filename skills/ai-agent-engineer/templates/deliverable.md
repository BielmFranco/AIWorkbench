# Agent contract

## Outcome and baseline
User result, simplest baseline, reason autonomy is needed, and completion observable.

| Tool | Input/output schema | Authority | Effect/idempotency | Timeout/recovery |
| --- | --- | --- | --- | --- |
| Capability | Typed fields | Server check and existing authorization | State boundary and retry key | Limit and unresolved-state behavior |

## State and escalation
Transitions, ownership, attempt/time budget, unresolved state, and handoff condition.

## Evaluation evidence
Design checks or executed trials, final-state verifier, failure cases, latency/cost, and limitations.
