# Contribuindo

1. Mantenha cada skill focada e com gatilhos discriminantes.
2. Atualize os casos correspondentes em `evals/cases/`.
3. Execute `python scripts/validate.py` e `python scripts/run_evals.py`.
4. Declare testes não executados e mudanças de comportamento.

Não inclua segredos, dados privados ou resultados inventados.
