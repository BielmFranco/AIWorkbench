# Release checklist

- [ ] Entrypoints and actually referenced resources exist; no mandatory empty scaffold.
- [ ] Metadata matches directories.
- [ ] Selection and outcome cases use realistic inputs with their own criteria.
- [ ] Worked examples are reachable from the entrypoint.
- [ ] Deterministic checks pass.
- [ ] Behavioral evidence is real or marked not run.
- [ ] Packaging produces valid ZIPs.
- [ ] Grader controls accept correct alternatives and reject wrong/incomplete outcomes.
- [ ] Pending human judgments and development-fixture leakage are disclosed.
